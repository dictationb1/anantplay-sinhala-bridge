Sinhala Subtitle Bridge v3 — the zero-fork engine behind the AnantPlay SI Companion

Worker තත්ත්වය · Worker status

ක්ෂණික පරීක්ෂණය · Quick verification (also proves the Gemini secret works)

Type any movie or series name — or paste an IMDb id. The worker resolves it (Cinemeta), looks for human Sinhala subs first, and only then starts a Gemini Flash EN→SI translation. The Companion app does all of this by itself; this box just proves the backend is alive.

    Companion යෙදුම · The companion app

    The standalone anantplay-si-companion Android app reads the player of the official, unmodified AnantPlay APK through accessibility, then locks each English cue it shows to the paired Sinhala cue from /api/paired/<jobId>.json — frame-exact, offline after the first fetch, zero typing. Its Worker URL defaults to this origin.

    යතුරු · Optional keys (only if the worker secrets are NOT set)

    Prefer the worker secrets (wrangler secret put GEMINI_API_KEY / wrangler secret put SUBDL_API_KEY) — nothing is then typed on any phone. The fields below are the emergency fallback: they are sent as request headers and kept only in this browser's localStorage.

    අතින් උපසිරැසි ප්‍රකාශය · Publish a local .srt / .zip / .gz

    Downloaded a Baiscope / Zoom / PirateLK file by hand? Publish it here and give the real .srt URL to AnantPlay (player → Subtitles → search) or to the Companion's emergency loader. The file is validated client-side first (cue count + timestamps must survive the round-trip) and is capped at 2 MB.

      API · Endpoints (for power users and the Companion)

      • GET /api/resolve?title=Clayface&type=movie
      • GET /subtitles/movie/tt34890576.json?title=Clayface
      • GET /api/paired/movie:tt34890576:0:0.json
      • GET /sub/<token>.srt (202 with progress while translating)
      • GET /api/status · GET /health

      AnantPlay stays 100% official and unmodified — this bridge and the companion app are separate, additive tools.
